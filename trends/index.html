METHOD / LIMITS

A snapshot, not a measuring instrument

Google Trends scales each request from 0 to 100 for its selected query, location, property, and time range. A value of 100 means “the peak in this request,” not 100 searches.

The page stores the exported values in JSON. To refresh it, open a card’s source URL, use Google Trends’ chart download button, and run the parser documented in the refresh note.

Data source: Google Trends. The current official API is an alpha program with limited access.

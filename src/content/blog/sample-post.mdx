## Native HTML inside a post

HTML can add structure without another UI framework. Here is a disclosure, with native keyboard support:

<details>
  <summary>What is happening here?</summary>
  <p>This is a native HTML details element. It works without JavaScript and can contain text, links, lists, and other ordinary content.</p>
</details>

A few inline HTML elements are also useful: press <kbd>Tab</kbd> to move between controls, use <mark>a short highlight</mark> for a point of interest, and write H<sub>2</sub>O or 2<sup>8</sup> when the text needs it. <abbr title="HyperText Markup Language">HTML</abbr> abbreviations can carry an explanation.

## A reusable interactive component

This is an Astro component imported into MDX. It uses native HTML controls and a small JavaScript custom element. React is not required.

<ReadingLab size={18} />

Move the sliders with a pointer or the arrow keys. Text size changes only the preview inside the component. Reading time uses an illustrative 1,200-word article. Reset restores the defaults. No preferences or input leave the browser.

This is all the article needs to include it:

```mdx
import ReadingLab from '../../components/ReadingLab.astro';

<ReadingLab size={18} />
```

## Embed a standalone experiment

An iframe can contain a separate HTML page or a complete tool. This one loads the site's existing shader playground only as you approach it. It keeps its own controls and document layout.

<iframe className="article-embed" src="/shader/" title="Interactive image shader playground" loading="lazy" height="560"></iframe>

[Open the shader playground on its own page](/shader/). For video or audio, we can use native media elements when there is a real, cleared media file to publish. An external player can also be embedded, but it introduces that provider's network requests. This specimen uses local content.

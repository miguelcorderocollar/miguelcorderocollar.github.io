How to read this page

Google Trends shows relative search interest from 0 to 100. A value of 100 is the peak inside that card’s query, place, property, and time range. It is not a search count.

Each card links to the exact Google Trends query used for its snapshot. To refresh one, download the chart CSV and follow the refresh note.

A card can use a shorter editorial cutoff when the useful story has already ended. The card states when that happens; the source link still opens the full Trends window.
